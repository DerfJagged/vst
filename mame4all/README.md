# mame4all

This is a pre-compiled version of osresearch's [mame4all-pi](https://github.com/osresearch/mame4all-pi) fork for vector games for use with v.st.

To use, copy to a Raspberry Pi, open a terminal to that folder, and enter `sh ./run.sh` (or if you know the game you want to play, `sh ./run.sh tempest`).
If you have `xboxdrv` installed, it will automatically enable use of a connected Xbox 360 controller.

You may need to chmod 777 the run.sh file.
